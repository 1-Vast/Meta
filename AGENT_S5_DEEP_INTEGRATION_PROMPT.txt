一、用户的最终要求
======================================================================

目标不是继续堆叠 ESM、GNN、CrossAttention、知识图谱或任意 latent module，而是回答并实现下面的可证伪主问题：

    frozen sequence/2D frontend
        -> correct-protein local geometry
        -> biologically named pair-local structural mechanism
        -> transferable correct-protein affinity increment
        -> k<=5 identifiable support section
        -> compact observable biological z
        -> unchanged K(B(z)F(z)) probability-law operator

最终模型必须体现“生物机制决定统计坐标，真实 affinity 决定方向，support rank 决定可适配维度”，而不是把生物特征简单拼接到一个通用深度网络前面。

自监督/结构监督学习可以与以前的创新模块合并，但它必须是训练阶段和唯一机制桥梁，不是新增并行大模型。正确的最终结构候选是：

    protein sequence + ligand graph
        -> existing frozen ESM + GINE
        -> existing frozen P1B contact/distance geometry
        -> structure-supervised pair-local mechanism head
        -> only Gate-passing named mechanism channels
        -> source-only affinity calibration
        -> rank-aware k<=5 support section
        -> z_bio
        -> unchanged CSMO / Band / K

结构 3D teacher 只在训练阶段存在；推理时不依赖真实 holo 坐标。旧 MIF、旧 PCA readout、旧 generic MAP、旧 Q-PMA、任意 pair latent 和新机制通道不得并联堆叠。新模块若通过，应替换旧失败功能；若失败，应删除实现并把结论写入 history.md。

三、当前已经证明和未证明的事实
======================================================================

已经证明：

- P0 数据合同和标签防火墙有效。
- P1A 开源 holo corpus 可治理、可复现。
- P1B 的 contact/distance geometry 对正确蛋白明显敏感；geometry identified。
- ChEMBL37 D0-C/D1 已建立 release-pinned Ki/Kd corpus，homology/document closure 跨 fold 为零。
- 旧 index-wise readout 不满足 permutation invariance。
- chemistry-aligned radial/typed basis 可以形成 partner-dependent structural statistic。
- 历史 global MIF、PCA、Ridge/Spline/MLP、interaction residual 和 shared radial affinity readout 均未建立稳定 correct-protein affinity increment。
- XP1/XP2 在已消费 kinase panels 中观察到 interaction/low-rank development signal，但 k<=5、double-held-out 和 external replication 未通过。
- 更广 BindingDB panels 的 assay noise 高于估计 interaction；低噪声 panel 的独立 protein groups 太少。
- S2 的六通道 3D 结构伪教师具有机器精度的旋转/平移/排列不变性。
- S4 的 mean-pooled ESM + ECFP Ridge 可预测部分复合物级聚合通道，但信号由 ligand 主导。

没有证明：

- S4 不是整个 sequence+2D 类的 upper bound。它没有测试 P1B atom-local、residue-local 和 atom-by-slot contact/distance，因此 pose-free 路线尚未关闭。
- 没有证明 P1B local states 能重建 protein-specific structural mechanism。
- 没有证明任何结构通道包含真实 affinity direction。
- 没有 biological statistic 被准入 z。
- 没有验证过 end-to-end DTA model。
- 没有证明 typed structural pseudo-label 等于物理自由能。
- 没有证明 k<=5 support 足以适配任何尚未通过 affinity Gate 的机制 basis。

------------------------------
S5-A：数据、链和映射合同
------------------------------

建立确定性映射：

    CCD atom serial <-> canonical ligand graph atom index
    mmCIF polymer residue <-> canonical target sequence index
    canonical sequence index -> P1B 128-slot index

必须审计：

- atom mapping coverage；
- residue mapping coverage；
- exact element/bond/charge/ring consistency；
- chain multiplicity；
- ligand 是否接触单链或跨链界面；
- residues per occupied slot；
- mixed biochemical classes per slot；
- modified residues、covalent ligands、peptide ligands、cofactors、metals/waters；
- discard reasons 和每行 provenance/hash。

Primary stratum 只允许部署合同可以表达的单 target-chain、单 non-covalent drug-like ligand。Homo-oligomer 和跨链口袋单独报告，不得混入 primary 后声称 sequence-only 可观测。

任一关键映射低于冻结门槛或 split 泄漏，fail closed：

    S5_DATA_OR_MAPPING_CONTRACT_FAIL_CLOSED

------------------------------
S5-B：chemistry-faithful pseudo-teacher 和 slot ceiling
------------------------------

当前 S2 teacher 是确定性结构伪教师，不是自由能 ground truth。应在 research/ 中实现新的 versioned teacher，使用：

- CCD/RDKit bond graph；
- formal charge；
- explicit donor/acceptor；
- aromatic ring membership/normal；
- protein residue atom chemistry；
- pair-local contribution 和明确 normalization。

第一版不要无条件加入所有机制。优先考虑部署上有可能识别、定义清楚的核心通道：

- directional H-bond association；
- signed ionic/electrostatic association；
- hydrophobic contact/burial；
- aromatic orientation association；
- steric overlap/clash；
- pocket/contact coverage。

水桥、金属配位、完整 protonation、solvation、entropy 明确标记 unobserved，不得伪造。

必须通过：

- rotation/translation invariance；
- ligand atom permutation；
- residue permutation；
- determinism；
- channel non-degeneracy；
- exact pair contribution -> aggregate reconstruction；
- exact residue -> 128-slot deterministic aggregation；
- explicit slot chemistry oracle ceiling；
- averaged ESM slot state 的信息损失审计。

比较 exact-residue teacher、slot-summed teacher、explicit slot composition 和 averaged ESM slot。若 slot/teacher/evaluation 自身失败，停止并记录：

    S5_TEACHER_OR_SLOT_CONTRACT_DEFECT

------------------------------
S5-C：actual frozen-P1B observability ladder
------------------------------

必须使用真实 P1B preprocessing 和 checkpoint，不得再用 mean-pooled ESM+ECFP 冒充全模型 upper bound。复用已有 production scripts/contracts，必要的新代码只能先放 research/。

固定 arms：

    C0  train mean
    C1  ligand-only local chemistry
    C2  pooled ESM + ECFP historical continuity
    C3  atom chemistry x explicit slot chemistry, no P1B geometry
    C4  C3 + frozen P1B contact and 5-bin distance probability
    C5  C4 + frozen atom-local and residue-local states
    CO  exact holo coordinate/teacher chemistry oracle ceiling
    CR  capacity-matched random features
    CD  score-blind <40% wrong protein from same split
    CG  within-complex pair-geometry shuffle

CD 只是 nuisance corruption control，不是 non-binder。映射必须在 score 前冻结、不同 closure、identity<40%、限制复用、记录 SHA。所有 scaler、normalizer、negative sampling、feature selection 只能在 train 拟合。不得根据 test 结果选择 channel、模型或阈值。

先使用确定性线性/低秩/小型 probe 定位信息。不要在这个阶段进行 architecture sweep。必须区分：

- CO FAIL：teacher/mapping/evaluation defect；
- CO PASS、C5 FAIL：tested pose-free P1B observable insufficient；
- C5 PASS：才授权 synthetic control 和轻量 GPU distillation。

------------------------------
S5-D：synthetic trainability positive control
------------------------------

用冻结 C5 输入构造已知可实现的 pair-local synthetic teacher。要求候选 head 在 held-out closure components 上恢复 correct target，并超过：

- ligand-only；
- deranged protein；
- pair geometry shuffle；
- label shuffle/random features。

记录 full train/validation curves、gradient norm、prediction variance、channel scaling、overflow/non-finite、train-vs-holdout gap。若 synthetic 失败，不得解释为 biology absence，结论只能是：

    S5_HEAD_OR_OPTIMIZATION_NOT_IDENTIFIED

不得事后加 epoch、调 hidden width、调 LR 或重跑 seed 挑最好结果。任何新 solver/architecture 必须另行预注册。

------------------------------
S5-E：轻量 pair-local structure-supervised distillation
------------------------------

只有 S5-A/B/C/D 通过才运行。使用 drug 环境和 CUDA。硬件按 RTX 4060 Laptop 8GB 设计。

冻结：

- ESM；
- ProteinEncoder；
- ligand GINE；
- P1B bridge；
- contact head；
- distance head。

只训练小型共享 pair map：

    u_ij = [
        atom-local state,
        residue-slot-local state,
        atom chemistry,
        explicit slot composition,
        p(contact_ij),
        p(distance_ij in 5 bins)
    ]

    e_ij = g_theta(u_ij) in R^C
    E(P,L) = permutation-invariant masked aggregation of e_ij

建议 1–5M 以内参数，batch 2–4，AMP，gradient accumulation 4–8，缓存 frozen frontend，atom-slot chunking，避免保留巨大 [B,N,128,H] tensor。先做 capacity/memory dry run。

Primary loss 是 train-only robust-scaled pair-local Huber，在 complex 内平均，再在 closure components 间平衡。可预注册小权重 aggregate Huber，但不得用 aggregate loss主导。禁止：

- affinity label；
- global ligand/protein embedding shortcut；
- target/ligand/assay ID；
- wrong-protein negative training；
- dataset-specific constant；
- DAVIS/recipient；
- 同时微调整个 P1B。

结构 feasibility criterion 至少要求一个预注册核心通道在新的 sealed confirmation block 上同时满足：

    R2(correct vs mean) >= 0.02, 95% LCB > 0
    R2(correct)-R2(ligand-only) >= 0.02, 95% LCB > 0
    R2(correct)-R2(deranged) >= 0.02, 95% LCB > 0
    R2(correct)-R2(pair-shuffle) >= 0.02, 95% LCB > 0

pair-local 和 complex aggregate 必须同方向。统计/bootstrap 单位是 homology/scaffold closure component，不是 atom-residue pair。

当前已经打开的 1,118 S4 complexes 是 development-exposed，不能再次称为 untouched test。必须从未暴露 RCSB entries 中 score-blind seal 新确认集，在 teacher score、channel selection、model selection 前冻结 PDB、homology、scaffold 和文件哈希。

互斥 terminal verdict：

    S5_DATA_OR_MAPPING_CONTRACT_FAIL_CLOSED
    S5_TEACHER_OR_SLOT_CONTRACT_DEFECT
    S5_HEAD_OR_OPTIMIZATION_NOT_IDENTIFIED
    P1B_PAIR_LOCAL_MECHANISM_NOT_OBSERVABLE
    P1B_PAIR_LOCAL_STRUCTURAL_MECHANISM_OBSERVED

只有最后一个允许另行注册 real source-affinity stage；它不等于 affinity identified。

六、自监督如何与历史创新合并，避免模型堆砌
======================================================================

遵守以下硬规则：

1. 自监督是训练阶段，不是并行 inference model。
2. 3D teacher 训练后删除部署依赖；推理只使用 sequence+2D/P1B。
3. 新 pair-local mechanism head 应替换旧 MIF/generic MAP/arbitrary pair projection，不与它们拼接。
4. 288D typed/radial basis只作为诊断或 teacher-coordinate witness；最终只保留通过 structure+affinity Gate 的少量 named channels。
5. 不恢复 Q-PMA。Few-shot support 以后只允许适配已通过 Gate 的机制通道。
6. CSMO/Band/K 不修改；只改变未来 z 的生物统计来源。
7. 一个模块只有在回答独立可证伪问题并通过自己的 Gate 后才能存在于最终模型。
8. 如果 structural PASS 但 affinity FAIL，mechanism head不得进入 z。
9. 如果 zero-shot affinity PASS 但 few-shot adapter FAIL，保留 population mechanism，删除 adapter，不宣称 meta-learning 增益。

目标最终不是：

    ESM + GINE + CrossAttention + MIF + KG + QPMA + CSMO

而是：

    one frozen geometry trunk
        + one Gate-passing named mechanism basis
        + one low-dimensional identifiable support section
        + unchanged probability-law operator

七、结构 PASS 后的后续阶段，只能条件注册，不能自动执行
======================================================================

------------------------------
E-AFF：source-only affinity calibration
------------------------------

只有 S5 structural PASS 才允许设计。优先使用已治理的 ChEMBL37 static Ki/Kd；BindingDB archived snapshot 用作独立 replication。不得混合 Ki/Kd/IC50 absolute labels；endpoint/context 分开。使用严格 outer-fold OOF ligand prior 和 same-task residual/difference supervision。

候选 population model 只能读取冻结 named mechanism channels，不能读取 target ID、assay ID 或 global ligand shortcut。Deranged protein 不进入训练，只进入评价。

Source Gate：

    CI_correct - CI_ligand >= 0.03
    CI_correct - CI_deranged >= 0.03
    both 95% component-bootstrap LCB > 0
    Spearman_correct > Spearman_deranged
    correct-protein positive increment must be true

先 source closure-OOF，PASS 后才能一次性 sealed transfer。DAVIS/recipient 在没有明确重新授权前仍冻结。

区分：

- source OOF FAIL：机制没有识别 affinity semantics；
- source PASS、transfer FAIL：novel-target transfer failure；
- 两者 PASS：才可称 affinity mechanism identified。

------------------------------
S-SECTION：k<=5 rank-aware meta-adaptation
------------------------------

只有 frozen population mechanism 通过 affinity Gate 后研究。禁止 arbitrary 128D support memory。设 named mechanism vector x(P,L) in R^d，尽量 d<=5。对 support matrix X_S：

    P_S = projector onto row(X_S)
    rank(X_S) <= k
    a_t = P_S f_theta(S)
    delta_q = x_q^T a_t

必须报告 rank、singular values、condition number、query row-space coverage。若 query 未被 support 覆盖或条件数过差，输出 zero adaptation + SECTION_UNIDENTIFIED/abstention，不得依靠 ridge prior 冒充识别。

正确 support 必须胜过：

- zero adaptation；
- permuted support labels；
- foreign-target support；
- amplitude-matched random correction。

冻结理论只覆盖其明确声明的 point-valued regression scope，不自动证明 ranking/listwise guarantee。任何理论声称必须引用具体 frozen theorem 前提并核对 compactness、observability、gauge、noise、coverage 和 abstention。

------------------------------
Z-BIO：production admission
------------------------------

只有 structure、source affinity、sealed transfer、few-shot section 全部通过后，才允许定义 compact observable bounded z，例如：

    z_bio = [
        named query mechanism channels,
        support-conditioned correction,
        query coverage,
        inverse conditioning,
        identifiable rank/k,
        declared uncertainty/radius,
        endpoint/context gamma
    ]

bounding 必须来自物理/结构合同或预注册稳定映射，不能使用 test min/max。不得把 synthetic constants、target ID、assay ID 或 query label放入 z。完成 admission 后才测试 unchanged K(B(z)F(z))。
