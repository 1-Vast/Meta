# Pre-R0 Few-Shot Lineage Summary

This file replaces the loose 2026-08-12 through 2026-08-14 experiment trees
that were removed from the working tree on 2026-08-16. Their full leaf
artifacts remain recoverable from Git commit `c61cb8a` and earlier history.
The current numerical authorities begin with the governed 2026-08-15 Stage 0
audit and the R0-R14 double-cold lineage.

## Closed families

| family | tested idea | retained conclusion |
|---|---|---|
| QPSMP analytic/LIRMS | fixed mathematical sections, ridge and analytic adaptation | Closed. Solvers and analytic sections did not establish cold-target SAR and conflict with the active forward-only contract. |
| HyperSAR | support code, Siamese differences, residual binding, LOO matching | Closed. The structural branch was neutral or harmful, k=1 centered evidence collapsed, and label-binding controls did not pass. |
| D-MEMT/DORM | mechanism prompts and difference-conditioned meta transport | Closed. Synthetic contracts could pass, but the learned mechanism did not become a positive performance source on governed BindingDB episodes. |
| CIPF/TERM | primitive fields and label-bound moment/evidence routing | Closed. Primitive semantics and scale were not identifiable; the transport path was weak or label-insensitive and contained dead or mis-scaled control paths. |
| K3/ELMT | interaction-first residual kernels and context variants | Superseded by the governed Stage 0-R14 lineage. The useful survivor was fixed Morgan/Tanimoto support weighting at k>=2, not the learned gate. |
| main_v1 / oracle probes | vectorization, support-only MLPs, ligand-residual heads and oracle section probes | Diagnostic only. They established implementation and information limits but are not retained model candidates. |
| early BPSF/QPSMP smoke runs | batching, cache, atom/residue and medium-size resource checks | Engineering findings were absorbed into the current data/model tests; checkpoints and prediction payloads were reproducible and removed. |
