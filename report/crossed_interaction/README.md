# Crossed-Interaction Evidence

This directory is the artifact counterpart of `research/crossed_interaction/`.
Directory families group C/Q observables, localization variants, SAR-delta,
rectangle controls, and protein/ligand ablations.

The large set of ridge-suffixed directories records failed sensitivity sweeps;
they are historical evidence and are not candidates for the active model.
Start with `../EVIDENCE_LEDGER.md` rather than scanning every leaf directory.
