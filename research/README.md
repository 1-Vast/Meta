# Research Prototypes

Nothing in this directory is active production authority. Scripts remain here
because maintained tests import them and because they explain retained negative
results.

- `meta_fewshot/`: earlier few-shot models, synthetic operators, and corpus
  builders. Results were consolidated under `report/meta_fewshot/`.
- `crossed_interaction/`: protein-specific C/Q, SAR-delta, localization, and
  rectangle experiments. Results live in `report/crossed_interaction/`.
- `correspondence_router/`: exact-structure correspondence panels.
- `e0_identifiability/`: directional/tensor-basis identifiability pilots.
- `source_affinity/`: ChEMBL source-assay SAR-delta study.

Failed scripts are comparators, not suggestions to reopen ridge or closed-form
adaptation. New active model work belongs in `model/` and `scripts/train_qpsmp.py`.
