# PKIS mechanism pilot

This directory is an isolated external falsification study.  It does not modify
or authorize `model/`.

Read in order:

1. `PREREGISTRATION.md` — v1 frozen radial/pharmacophore-shell pilot.
2. `artifacts/run_v1/result.json` — retained negative v1 result.
3. `REVISION_V2_PREREGISTRATION.md` and `REVISION_V2_FREEZE.json` — the one
   permitted local-environment product-kernel revision and its pre-score hashes.
4. `artifacts/run_v2/result.json` — v2 development and external transfer result.
5. `FINAL_REPORT_ZH.md` — interpretation, decision, and theory integration.

Minimal CPU environment:

```bash
python -m venv .venv
.venv/bin/pip install pytest numpy pandas scipy scikit-learn rdkit openpyxl xlrd
```

Tests:

```bash
.venv/bin/python -m pytest -q \
  research/pkis_mechanism_pilot/test_mechanism.py \
  research/pkis_mechanism_pilot/test_kernel_revision.py
```

The v2 runner expects the public Informers repository, the official KLIFS human
kinase JSON response, the Anastassiadis Supplementary Table 3 workbook, and the
identity sidecar generated by `resolve_anastassiadis.py`.  Exact input hashes and
the executed branch/head are recorded in each run manifest.
