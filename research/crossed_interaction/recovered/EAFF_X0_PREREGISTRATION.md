# E-AFF-X0 Crossed Target-Ligand CensusStatus: registered before querying ChEMBL metadata, constructing panels, orcounting rectangles. X0 is strictly label-blind and cannot access affinityvalues, published values, pChEMBL, or recipient/DAVIS labels.## QuestionDoes the governed ChEMBL37 Ki/Kd source contain enough independent, compatible`2 targets x 2 ligands` panels to test a real protein-by-ligand interaction?X0 is a data census, not an affinity experiment. It does not computedouble-difference values or train a model.## Inputs And Label Firewall- `e0_input_v1/rows.label_blind.jsonl` supplies the immutable governed activity  IDs, protein hashes, ligand connectivity, closure components and folds.- The pinned ChEMBL37 SQLite supplies metadata only for those activity IDs.- The SQL projection is prohibited from selecting `standard_value`, `value`,  `pchembl_value`, or any other affinity field.- Release, input and code hashes are bound in the output manifest.## Primary Compatible PanelRows share a primary crossed-panel key only when all of these match exactly:- document;- endpoint (`Ki` and `Kd` remain separate);- assay organism;- BAO format;- cell, tissue and subcellular-fraction identifiers;- relationship type;- canonical assay-parameter payload.Variant assays are excluded from the primary stratum. Target accession,sequence, component ID, assay ID and target-dependent context fields are notpart of the panel key. Assay descriptions are retained for audit but are notparsed into a learned or hand-tuned protocol family.A cell is `(panel, protein sequence, ligand connectivity)`. Multiple governedactivities in the same cell are retained as replicate provenance. A rectanglerequires two distinct protein sequences and two distinct ligand connectivitykeys with all four cells present.## Dependency And IndependenceRectangles are not treated as IID. All rectangles within a panel are dependent.Panels are additionally joined when they touch the same D1homology-document closure component. The effective X0 unit is a connectedcomponent of this panel-closure bipartite graph. Rectangle counts aredescriptive only; all feasibility decisions use effective component counts.## Replicate Strata- `replicate_supported`: each of the four cells has at least two governed  measurements within one exact assay ID. This may support later  measurement-noise estimation.- `no_replicate`: the rectangle exists, but at least one cell lacks exact-assay  replication. It may support an additive-null X1 but not a noise-corrected  thermodynamic claim.Absence of exact-assay replication is never converted to zero measurementnoise.## Frozen Feasibility BoundThe design target is an interaction RMS equal to `0.5` assay-noise standarddeviations. Under an ideal independent one-sided chi-square variance test with`alpha=0.05` and `power=0.80`, the first integer meeting the power target is`245` independent units. This is a lower-bound design calculation, not a claimthat clustered/non-Gaussian X1 will attain that power.Ki and Kd are evaluated separately. Terminal verdicts are:- `X0_NOISE_AWARE_CROSSED_DATA_SUPPORTED_<ENDPOINT>`: at least 245 effective  replicate-supported components for that endpoint.- `X0_ADDITIVE_NULL_ONLY_CROSSED_DATA_SUPPORTED_<ENDPOINT>`: fewer than 245  replicate-supported but at least 245 total effective components.- `STOP_SOURCE_INTERACTION_UNDERDETERMINED`: neither endpoint has 245 total  effective components.- `X0_DATA_OR_LABEL_FIREWALL_FAIL_CLOSED`: metadata, release, closure or label  firewall contract fails.An X0 data-support verdict authorizes only a separately registered X1 for thenamed endpoint and replicate stratum. It does not authorize value access in X0,X2, orientation, RFSA, DAVIS, production integration, or P2-P4.## Required Outputs- label-blind panel and cell manifests;- per-endpoint panel/target/ligand/cell/rectangle counts;- replicate-supported counts;- panel-closure dependency assignments and largest-component fraction;- exact SQL projection and all input/output SHA-256 values;- explicit `affinity_value_fields_selected=0`, `davis_label_reads=0`, and  `recipient_label_reads=0`.
